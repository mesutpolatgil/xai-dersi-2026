Bölüm 22 • Functional Decomposition

Karmaşık Bir Modeli Anlaşılır Parçalara Ayırmak

Yüksek boyutlu bir tahmin fonksiyonunu sabit kesişim, tekil ana etkiler ve etkileşim bileşenlerinin toplamı olarak yazma yöntemidir.

f(x1, x2) = 2 + ex1 − x2 + x1·x2  ⇒  f0 + f1(x1) + f2(x2) + f12(x1, x2)

Slayt 22 • Bağımsız Özellikler

1. Fonksiyonel ANOVA

Diğer özellikler üzerinden ortalama alır ve alt mertebe etkileri çıkarır.

  • • Sıfır Ortalama: Her etki sıfır etrafında dalgalanır.
  • • Diklik: Bileşenler birbirine bilgi sızdırmaz.
  • • Varyans Ayrıştırması: Parçaların varyansları toplamı toplam varyansı verir.
Slayt 23 • Bağımlı Özellikler

2. ALE (Apley ve Zhu, 2020)

Özellikler korelasyonlu olduğunda fANOVA gerçek dışı kombinasyonlar üretir.

  • • Toplamsallık: ALE bileşenlerinin toplamı f fonksiyonunu verir.
  • • Sözde Diklik: Korelasyonlu veride etkileri birbirine karıştırmaz.
  • • PDP Farkı: PDP alt etkileri de içerdiğinden toplamı f'yi vermez.
Slayt 24 • Yapısal Modeller

3. Ağaçlar ve GAM / GA2M

Modeli sonradan ayrıştırmak veya en baştan sade kurmak.

  • • Ağaç Toplulukları (Yang vd., 2024): Ağaç derinliği 2 ise yalnızca ana ve ikili etkiler çıkar.
  • • Aşağıdan Yukarıya (GAM): Yalnızca ana etkiler ve ikili etkileşimlerle (|S| ≤ 2) model kurulur.

Hücre 1: Bölüm 21 - Penguenler H-İstatistiği (Şekil 1 & Şekil 2) 
import warnings
warnings.filterwarnings('ignore')

import pandas as pd
import numpy as np
import seaborn as sns
import matplotlib.pyplot as plt
from sklearn.ensemble import RandomForestClassifier
from sklearn.inspection import partial_dependence

# 1. Penguen verisini yükle ve hazırla
df = sns.load_dataset('penguins')
features = ['species', 'bill_length_mm', 'bill_depth_mm', 'flipper_length_mm', 'body_mass_g']
df = df[features + ['sex']].dropna()

df['species_code'] = df['species'].astype('category').cat.codes
X = df[['species_code', 'bill_length_mm', 'bill_depth_mm', 'flipper_length_mm', 'body_mass_g']].copy()
X.columns = features

# KRİTİK ÇÖZÜM: partial_dependence için tüm sütunları float yapıyoruz
X = X.astype(float)
y = (df['sex'] == 'Male').astype(int)

# 2. Rastgele Orman modelini eğit
rf = RandomForestClassifier(n_estimators=100, random_state=42)
rf.fit(X, y)

# 3. İkili Friedman H-İstatistiği fonksiyonu
def compute_h_stat_pair(model, X_data, feat_j, feat_k, grid_res=20):
    pd_j = partial_dependence(model, X_data, features=[feat_j], grid_resolution=grid_res)
    pd_k = partial_dependence(model, X_data, features=[feat_k], grid_resolution=grid_res)
    pd_jk = partial_dependence(model, X_data, features=[feat_j, feat_k], grid_resolution=grid_res)
    
    f_j = pd_j['average'][0] - np.mean(pd_j['average'][0])
    f_k = pd_k['average'][0] - np.mean(pd_k['average'][0])
    f_jk = pd_jk['average'][0] - np.mean(pd_jk['average'][0])
    
    diff = f_jk - (f_j[:, None] + f_k[None, :])
    pay = np.sum(diff ** 2)
    payda = np.sum(f_jk ** 2)
    return np.sqrt(pay / payda) if payda > 0 else 0.0

# 4. Vücut kütlesi (body_mass_g) ikili etkileşimlerini çizdir (Slayt 9)
other_features = ['bill_depth_mm', 'bill_length_mm', 'species', 'flipper_length_mm']
pair_scores = {f"{f}:body_mass_g": compute_h_stat_pair(rf, X, f, 'body_mass_g') for f in other_features}
s_pairs = pd.Series(pair_scores).sort_values()

plt.figure(figsize=(8, 4))
plt.hlines(y=s_pairs.index, xmin=0, xmax=s_pairs.values, color='black', linewidth=1.5)
plt.plot(s_pairs.values, s_pairs.index, 'o', color='black', markersize=6)
plt.xlabel('Overall interaction strength (H-İstatistiği)')
plt.ylabel('Features')
plt.title('Bölüm 21 - Şekil 1: Vücut Kütlesi (body_mass_g) İkili Etkileşimleri')
plt.xlim(0, max(s_pairs.values) * 1.15)
plt.grid(True, linestyle='--', alpha=0.5)
plt.tight_layout()
plt.show()

# Kitaptaki fonksiyon: f(x1, x2) = 2 + exp(x1) - x2 + x1 * x2
x1 = np.linspace(-1, 1, 100)
x2 = np.linspace(-1, 1, 100)
X1, X2 = np.meshgrid(x1, x2)
F_surface = 2 + np.exp(X1) - X2 + (X1 * X2)

# Bileşenlerin ayrıştırılması (Slayt 18-19)
f1_main = np.exp(x1) - np.mean(np.exp(x1))   # Ana etki f1 (Üstel)
f2_main = -x2 - np.mean(-x2)                 # Ana etki f2 (Doğrusal)
f12_inter = X1 * X2                          # İkili etkileşim f12 (Pringles yüzeyi)

fig, axes = plt.subplots(2, 2, figsize=(10, 8))

# Sol Üst: Ana etki f1
axes[0, 0].plot(x1, f1_main, color='black', linewidth=2)
axes[0, 0].set_title('Ana Etki $f_1(x_1)$')
axes[0, 0].set_xlabel('$x_1$'); axes[0, 0].set_ylabel('ALE of y')

# Sağ Üst: Etkileşim f12
c_inter = axes[0, 1].contourf(X1, X2, f12_inter, levels=25, cmap='plasma')
axes[0, 1].contour(X1, X2, f12_inter, levels=10, colors='black', linewidths=0.8)
axes[0, 1].axhline(0, color='black'); axes[0, 1].axvline(0, color='black')
fig.colorbar(c_inter, ax=axes[0, 1], label='value')
axes[0, 1].set_title('Etkileşim $f_{12}(x_1, x_2) = x_1 \cdot x_2$')

# Sol Alt: Ana etki f2
axes[1, 0].plot(x2, f2_main, color='black', linewidth=2)
axes[1, 0].set_title('Ana Etki $f_2(x_2)$')
axes[1, 0].set_xlabel('$x_2$'); axes[1, 0].set_ylabel('ALE of y')

axes[1, 1].axis('off')
plt.suptitle('Bölüm 22 - Şekil 4: Fonksiyonel Ayrıştırma Bileşenleri', fontsize=13, fontweight='bold')
plt.tight_layout()
plt.show()
