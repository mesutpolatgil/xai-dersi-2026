Permütasyon Özellik Önemi (Permutation Feature Importance - PFI)

Modeli Yeniden Eğitmeden Özellik Önemi Ölçümü (Şekil 23.1 & 23.2)

Test verisindeki bir j özelliğinin değerlerini rastgele karıştırarak özellik ile gerçek sonuç y arasındaki bağı koparırız. Karıştırma sonrası model hatası (eperm,j) orijinal hataya (eorig) göre ne kadar artarsa, o özellik tahmin için o kadar önemlidir.

// PFI Formülü
eorig = (1/n) ∑ L(y(i), f̂(x(i)))
eperm,j = (1/n) ∑ L(y(i), f̂(xperm,j(i)))
FIj = eperm,j / eorig (Oran)
